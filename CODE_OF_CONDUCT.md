# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its standards apply in every project space: issues, pull requests, reviews and discussions. They also apply
wherever someone represents the project.

In short: be respectful and patient, and assume good intent. Criticise ideas and code, not people. Some
behaviour isn't acceptable here: harassment, personal attacks, discriminatory language, and publishing
someone's private information.

## Reporting

To report a problem, contact the maintainer, [@ALIRAZA47](https://github.com/ALIRAZA47), privately, using
the contact details on their GitHub profile. Don't report it in a public issue. Reports are kept
confidential. The maintainer decides on any action, following the Covenant's enforcement guidelines.
